# BMP-Translations

 BMP Translations is a resource pack created by the BMProjects team. Its purpose is to add a variety of translations for mods to modpacks. We have specially developed such a project so that it would be more convenient for us to add translations, and other modpacks authors could use it for their projects!

## Repository structure

Resource-pack sources are stored unpacked in `packs/<minecraft-version>`.
Every Minecraft version has its own `VERSION` and independent release history.
ZIP files are validated and built automatically by GitHub Actions.

Release-system documentation:

- [English guide](docs/GUIDE_EN.md)
- [Русское руководство](docs/GUIDE_RU.md)

The shorter [RELEASING.md](RELEASING.md) reference is also available.
