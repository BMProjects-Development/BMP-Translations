# Соединитель ME-Replication

<Row gap="20">
<BlockImage id="rep_ae2_bridge:rep_ae2_bridge" scale="8"></BlockImage>
</Row>

Соединитель RepAE2Bridge — это компонент, соединяющий систему ME из AE2 с сетью материи Replication, обеспечивая бесшовную интеграцию между двумя системами.

## Возможности

Соединитель действует как переводчик между двумя системами, позволяя данным материи Replication быть доступными в системе AE2 ME, и наоборот.

Это позволяет Вам:
- Просматривать количество материи в сети Replication через терминалы AE2
- Запрашивать репликации через систему автокрафта AE2
- Настраивать приоритеты крафта для оптимального управления ресурсами

## Размещение

Чтобы разместить соединитель, выполните следующие шаги:

1. Установите блок соединителя RepAE2 в точке, которая имеет доступ к обеим сетям
2. Подключите кабель AE2 к одной из сторон блока
3. Подключите трубу материи Replication к другой стороне блока

## Настройка приоритетов

Соединитель включает систему приоритетов, позволяющую управлять порядком обработки запросов на крафт. Это особенно полезно, когда у Вас несколько соединителей или нужно расставить приоритеты для определённых типов предметов.

### Доступ к интерфейсу приоритетов

1. **Нажмите ПКМ** на блок соединителя, чтобы открыть интерфейс настройки приоритетов
2. Введите значение приоритета в числовое поле
3. Значение может быть в диапазоне от -2 147 483 648 до +2 147 483 647
4. Более высокие значения приоритета обрабатываются первыми
5. Более низкие значения приоритета обрабатываются позже

### Рекомендации по приоритетам

- **Положительные значения (1-1000)**: Высокий приоритет, обрабатываются раньше
- **Ноль (0)**: Приоритет по умолчанию, обычный порядок обработки
- **Отрицательные значения (-1 до -1000)**: Низкий приоритет, обрабатываются позже

### Примеры использования

- **Производственные соединители**: Установите высокий приоритет (100-500) для соединителей, обрабатывающих критически важные предметы производства
- **Резервные соединители**: Установите низкий приоритет (-100 до -500) для соединителей, предоставляющих резервную мощность крафта
- **Экспериментальные предметы**: Установите очень низкий приоритет (-1000+) для тестирования или экспериментального крафта

## Оптимальная настройка

* Используйте только одну сеть Replication на каждый соединитель
* По умолчанию соединитель может обрабатывать ~20 репликаторов одновременно
* Для поддержки большего количества репликаторов используйте ЦП крафта с большим количеством блоков обработки крафта
* Настройте приоритеты в зависимости от Ваших производственных потребностей и доступности ресурсов
