# Беспроводной Универсальный Терминал

<ItemImage id="ae2wtlib:wireless_universal_terminal" scale="3" />

<ItemLink id="ae2wtlib:wireless_universal_terminal" /> представляет собой комбинацию нескольких [Беспроводных Терминалов](wireless_terminals.md) в одном предмете.

Все [Беспроводные Терминалы AE2WTLib](wireless_terminals.md) могут быть объединены в один терминал.

<ItemLink id="ae2:wireless_terminal" /> из AE2 ***НЕЛЬЗЯ*** объединить в <ItemLink id="ae2wtlib:wireless_universal_terminal" />.


## Интерфейс

<ItemLink id="ae2wtlib:wireless_universal_terminal" /> добавляет кнопку в пользовательский интерфейс терминала,
по которой можно нажимать левой кнопкой мыши (и правой кнопкой мыши) для переключения на следующий (или предыдущий) [Беспроводной Терминал](wireless_terminals.md).


## Улучшения

<ItemLink id="ae2wtlib:wireless_universal_terminal" /> принимает те же улучшения, что и установленные [Беспроводные Терминалы](wireless_terminals.md).
Каждый установленный терминал добавляет 2 слота для улучшений.

## Хранение энергии

Добавление терминалов объединяет их энергохранилище,
поэтому <ItemLink id="ae2wtlib:wireless_universal_terminal" /> с двумя терминалами обладает вдвое большим энергохранилищем, чем [Беспроводной Терминал](wireless_terminals.md).
