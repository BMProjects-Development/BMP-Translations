# Квантовый Компьютер

Квантовый компьютер — это особый вид компьютера для крафта. Он способен выполнять неограниченное количество запросов на крафт, при условии наличия достаточного объема памяти для крафта.

## Квантовое Ядро

<BlockImage id="advanced_ae:quantum_core" p:powered="true" p:formed="true" scale="4"></BlockImage>

Квантовое ядро — это сердце Квантового Компьютера. Оно само по себе имеет 256М памяти для крафта и 8 потоков сопроцессора. Это единственный блок, который может самостоятельно создать сформированный квантовый компьютер и предоставить все его преимущества. Однако, если использовать его для создания мультиблока, можно создать гораздо более мощный компьютер. При использовании в качестве автономного компьютера питание должно подаваться через верхнюю или нижнюю стороны, где расположены разъемы.

## Квантовые Хранилища

<Row gap="20">
<BlockImage id="advanced_ae:quantum_storage_128" scale="4"></BlockImage>
<BlockImage id="advanced_ae:quantum_storage_256" scale="4"></BlockImage>
</Row>

Эти блоки расширяют память для крафта квантового ядра. Они эффективно увеличивают количество одновременных задач, которые может выполнять квантовый компьютер. Существует две вариации: с емкостью 128М и 256М.

## Квантовый Запутыватель Данных

<BlockImage id="advanced_ae:data_entangler" scale="4"></BlockImage>

Запутыватели данных — это особый блок, который влияет на все блоки хранения, присутствующие в мультиблоке. Они позволяют блокам хранения данных хранить данные в нескольких измерениях, эффективно умножая их объем хранения на 4. Только один такой блок может быть размещен в каждом мультиблоке квантового компьютера.

## Квантовый Ускоритель

<BlockImage id="advanced_ae:quantum_accelerator" scale="4"></BlockImage>

Квантовые ускорители добавляют 8 сопроцессоров к мультиблоку Квантового Компьютера. Важно отметить, что все шаблоны крафта, выполняемые квантовым компьютером, могут совместно использовать все сопроцессоры, поэтому, вероятно, хорошей идеей будет инвестировать в большое количество таких ускорителей.

## Квантовый Мультипоточник

<BlockImage id="advanced_ae:quantum_multi_threader" scale="4"></BlockImage>

Подобно Запутывателям Данных, мультипоточники позволяют ускорителям запускать дополнительные потоки в отдельных измерениях, умножая их сопроцессорную мощность на 4. Только один такой блок может быть размещен в каждом мультиблоке квантового компьютера.

## Мультиблок

Для создания мультиблочного квантового компьютера необходимо соблюдать следующие правила:
- Максимальный размер 7x7x7 (внешние размеры);
- Внутри мультиблока не должно быть пустых пространств. Их можно заполнить <ItemLink id="advanced_ae:quantum_unit" /> без каких-либо дополнительных преимуществ;
- Ровно одно <ItemLink id="advanced_ae:quantum_core" />;
- Не более одного <ItemLink id="advanced_ae:data_entangler" />;
- Не более одного <ItemLink id="advanced_ae:quantum_multi_threader" />;
- Все блоки на внешнем слое должны быть <ItemLink id="advanced_ae:quantum_structure" />;
- Ни один блок внутри не может быть <ItemLink id="advanced_ae:quantum_structure" />.

## Конфигурации Сервера

Некоторые значения могут быть настроены через конфигурации сервера. Например:
- Максимальный размер мультиблока;
- Сопроцессоры в каждом Квантовом Ускорителе;
- Максимальное количество Квантовых Мультипоточников;
- Значение умножения потоков Мультипоточника;
- Максимальное количество Запутывателей Данных;
- Значение умножения хранилища Запутывателя Данных;

Ограничения для вашего экземпляра можно проверить, используя всплывающие подсказки предметов.
