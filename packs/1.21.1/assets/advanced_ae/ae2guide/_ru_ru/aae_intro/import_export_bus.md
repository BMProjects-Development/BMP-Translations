# Шина импорта/экспорта

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../structure/cable_import_export_bus.snbt"></ImportStructure>
</GameScene>

Шина импорта/экспорта представляет собой комбинацию <ItemLink id="ae2:import_bus" /> и <ItemLink id="ae2:export_bus" />.
Фильтр может быть настроен для конфигурации экспортируемых стопок. Все, что не указано в фильтре, является допустимой стопкой для импорта.
