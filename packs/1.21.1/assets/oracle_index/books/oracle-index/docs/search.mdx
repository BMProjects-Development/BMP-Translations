Oracle Index оснащён интеллектуальной функцией поиска. Чтобы открыть окно поиска, нажмите [CTRL + ORACLE_HOTKEY] или клавишу быстрого вызова поиска (по умолчанию не назначена). 
Также есть небольшая иконка поиска при просмотре записи вики.

<Callout variant="info">
    Поиск также поддерживает математические вычисления и выражения!
</Callout>

При первом открытии экрана поиска может потребоваться несколько секунд на индексацию доступных страниц, прежде чем Вы сможете выполнить поиск. 
Поиск — это полноценный семантический поиск, работающий на основе машинного обучения. Это означает, что Вам не нужно искать по точным ключевым словам — 
Вы можете вводить целые предложения, и будет показан релевантный контент, даже если слова не совпадают дословно. Все соответствующие темы будут отображены.

## Технические детали
Под капотом Oracle Index генерирует эмбеддинги для всех страниц, которые предварительно разбиваются на фрагменты. 
Затем небольшая модель sentence-transformer (all-MiniLm-L6-V2-q) генерирует эмбеддинги для каждого фрагмента и для поискового запроса. 
Векторы эмбеддингов хранятся в памяти. Вектор эмбеддинга поискового запроса затем сравнивается с эмбеддингами фрагментов вики. Наиболее близкие N результатов отображаются пользователю.

Для этого используется библиотека Langchain4j, которая, в свою очередь, использует DJL Framework. Размер модели эмбеддингов составляет около 15 МБ.
