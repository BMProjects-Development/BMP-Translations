---
title: Руководство пользователя
---

Oracle Index — это клиентский мод для внутриигровой документации, предназначенный для просмотра содержимого с [moddedmc.wiki](https://moddedmc.wiki/) прямо в игре.

Разработчики модов могут включать свои вики в свои моды, а затем использовать мод Oracle Index для их отображения в игре. Нажмите клавишу привязки вики (по умолчанию [H]), чтобы открыть экран Oracle Index.
Для этого не нужна специальная книга или что-то подобное. При выходе из экрана запоминается место на котором Вы остановились.

Вы можете просматривать документацию мода только в том случае, если мод установлен, а его разработчик решил включить свою документацию с moddedmc.wiki в качестве вики Oracle Index.

## Переключение модов
В левой части экрана Вы увидите панель навигации для текущего выбранного мода. Чтобы переключиться на другой мод, просто нажмите на заголовок мода над панелью навигации.
Откроется выпадающий список, в котором можно выбрать мод для просмотра.

## Ссылки на предметы
Разработчики модов могут добавлять ссылки на вики внутриигровым предметам. Если для предмета доступна страница вики, Вы увидите небольшую дополнительную иконку в подсказке предмета.
Удерживайте кнопку [ALT], чтобы открыть соответствующую запись вики при просмотре подсказки предмета.

## Язык
Oracle Index автоматически отображает переведённое содержимое, если оно доступно. Переводятся как содержимое страниц, так и панель навигации. Поиск пока не поддерживает поиск 
по переведённому содержимому, но будет открывать результаты в переведённой версии, если она доступна.
