# Гайд по боссам Рагнарёка

Добро пожаловать в гайд по боссам FTB Ragnarok. Это руководство содержит подробную информацию о каждом боссе из скандинавской мифологии, их механиках и стратегиях победы над ними.

## Боссы

Боссы Рагнарёка олицетворяют силы хаоса и разрушения из скандинавской мифологии. С каждого босса выпадает уникальное сердце, которое дарует могущественные способности при поглощении.

## Прогрессия боссов

Рекомендуемый порядок сражения с боссами:

1. **Хель** - Королева подземного мира (Первый босс)
2. **Имир** или **Ёрмунганд** - Выберите свой путь
3. **Сурт** - Владыка огненных великанов
4. **Сколль и Хати** - Охотники за затмением
5. **Нидхёгг** - Пожиратель миров (Финальный босс)

## Общие советы

- У всех боссов есть **лимит урона** — максимум 10% от их максимального здоровья за один удар (магический урон игнорирует это ограничение).
- Боссы **сбрасывают** свое состояние, если вы слишком надолго покидаете их арену.
- У каждого босса есть уникальная **смена фаз**, открывающая новые способности.
- Во время боя будет играть уникальная **музыка босса** — собирайте пластинки с поверженных врагов!
