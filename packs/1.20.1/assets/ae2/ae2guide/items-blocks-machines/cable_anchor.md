# Кабельный якорь

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/assemblies/cable_anchor.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

Небольшие декоративные клинья для крепления кабелей, которые можно использовать для предотвращения соединения кабелей, создания лестниц с кабелями или придания кабелю видимости
соединенными со стенами вокруг него. Также используются для изготовления <ItemLink id="facade" />.

Кабельные якоря предотвращают образование соединений на стороне, на которой они установлены.

По ним можно подниматься, как по лестнице.
