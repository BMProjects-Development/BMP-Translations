# Стигийская наковальня

<BlockImage id="stygian_anvil" scale="5"/>

<ItemImage id="stygian_anvil" scale="0.5"/> Стигийская наковальня — это то, с чего начинается ваше путешествие в Woot Revived.

Чтобы создавать на ней предметы, вам нужно нажимать по ней ПКМ с <ItemImage id="stygian_hammer" scale="0.5"/> Стигийским молотом в руке. Подробнее в разделе [Начало работы](../getting-started.md).

Вы можете забрать предметы обратно, кликнув по наковальне пустой рукой с зажатым Shift.

Наковальню можно автоматизировать с помощью труб для предметов и <ItemImage id="netherite_magmator" scale="0.5"/> [Магматора](magmator.md).
